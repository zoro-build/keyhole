# Mac 系统如何关闭 SIP（系统完整性保护）

SIP（System Integrity Protection，系统完整性保护）只能在**恢复模式**里关闭，在正常系统中无法修改。

## 1. 先查看当前状态（可选）

打开「终端」，输入：

```bash
csrutil status
```

显示 `enabled` 表示已开启。

## 2. 进入恢复模式

- **Apple 芯片（M1/M2/M3/M4 等）**：先完全关机，然后**按住电源键不放**，直到屏幕出现“正在载入启动选项”，再点击「选项」→「继续」。
- **Intel 芯片**：重启后立即**按住 `Command + R`**，看到 Apple 标志或地球图标时松开。

需要的话，输入管理员账号和密码。

## 3. 打开终端

在顶部菜单栏选择「实用工具」→「终端」。

## 4. 关闭 SIP

```bash
csrutil disable
```

根据提示输入 `y` 确认，再输入管理员用户名和密码（新版 macOS 会要求）。看到成功提示后执行：

```bash
reboot
```

## 5. 验证

重启进入系统后，再次运行：

```bash
csrutil status
```

显示 `disabled` 就说明已经关闭。

---

## 补充说明

### 重新开启 SIP

按同样的方法进入恢复模式，在终端里执行下面的命令，然后重启：

```bash
csrutil enable
```
